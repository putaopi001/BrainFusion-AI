# R2 熵权 TOPSIS 工程协议 v1（2026-10-16 实施前冻结）

范围：独立离线组件与已观察拆分的探索性复核；不替换现有模型、latest 指针、API、研究页或论文结论。原 topsis.py 等准则算法逐字节保留。同协议自动掩膜队列对照、独立评价、统计与可靠性代理仍另验。

## 拟合信息与终点

方案为已训练分支，列固定为 validation AUC（收益）、threshold=0.5 的 balanced accuracy（收益）、Brier（成本）；三指标均有已知[0,1]界限。分支必须预测同一患者、同一原始事件 idh1/2=1。训练/特征选择不由此组件执行。所有全局权重仅用共同验证患者的三项汇总值拟合。调用方提供验证名单和被排除的训练/评价/工程名单，唯一性及交集检查必须通过；这只能验证声明，真实名单/源文件/旧训练身份由实验驱动核对。名单与准则矩阵、权重、回退原因随产物保存；加载后重新计算全状态并检查一致性。

本轮若复核旧模型，只读复用原来源SHA及已冻结98/21/22名单和旧模型bundle，校验旧summary/模型SHA/CSV输入SHA，核验验证指标复现后才计算融合；新结果仅写本轮新目录。22人已观察，不能称独立最终测试，原始0/1临床极性及MONAI重叠未解决。参考掩膜特征不可称自动掩膜模型准确性。

## 熵权与距离的确切定义

令 V 为分支×3的验证指标矩阵。熵拟合使用固定界限的质量 Q=(AUC,BA,1-Brier)，不对两方案做样本min–max（那会让所有非恒定列退化为同样[0,1]）。所有分支共享同列：任一分支该指标缺失NaN则整列弃用；无穷/超出[0,1]拒绝。列极差≤1e-12视恒定并置零准则权重；不以测试指标补缺。单分支返回1；全部列不可用时分支均匀。

对剩余列，p_ij=Q_ij/sum_i Q_ij；0 log0=0，H_j=-sum_i(p_ij log p_ij)/log(m)，d_j=max(0,1-H_j)，w_j=d_j/sum_j d_j。d总量≤1e-12时均匀分配到可用列并记录退化；数学零熵意味着最大离散度d=1，而不是自动异常。准则权重只是跨分支质量离散度，不证明重要性或临床可靠性；只有两个分支会极不稳定。

TOPSIS距离保持旧算法的原始指标列向量归一化形式：R_ij=V_ij/||V_.j||₂，零范数按1；Z_ij=w_j R_ij；正/负理想点按收益/成本方向取各列max/min。c_i=D_minus/(D_plus+D_minus)，距离和≤1e-12时c_i=0；最终全局分支权重a_i=c_i/sum c，贴近度总量≤1e-12时分支均匀。常量/缺失列不参与距离。贴近度不是疾病概率。分支并列保留相同权重；不加入按患者标签、真实Dice或真实误差生成的动态权重。

准则或分支最大权重>0.95标记 extreme_*，保留真实零/一权重，不根据结果裁剪、调阈值或保优。支配关系可使旧/新TOPSIS都坍缩到单分支；熵权不保证胜过平均或旧TOPSIS。

## 部署期缺失与状态

应用时声明的分支顺序必须与冻结顺序完全相同。非有限Inf/越界概率拒绝；仅NaN可显式表示缺分支，每患者在可用分支上重新归一化**已冻结**a。若其余可用分支全为零权重，均匀分配并记录原因；仅一个可用分支则用该分支。全部缺失则整批具体拒绝并列出行号，不伪造概率/默默删患者。输出每行有效权重和原因；不在推理时重估熵或用其他患者概率拟合权重。没有缺失时就是固定全局加权平均。

JSON保存schema、协议版本、固定准则/方向、原矩阵（缺失null）、名单及其SHA、有效列、熵/准则权重/距离/贴近度/分支权重、所有原因。加载拒绝未知字段/协议、改动的权重或名单SHA；JSON一致性不是密码学签名，真实性仍依赖独立产物SHA和来源登记。
