# BrainFusion AI — 项目概览

## 一、项目背景

脑胶质瘤（Glioma）是成人最常见的原发性颅内肿瘤，具有高致残率与高复发率。传统诊疗流程依赖医生逐层人工阅片，耗时且高度依赖经验。

BrainFusion AI 通过融合**医学影像分析、临床数据分析、多模型融合、AI 解释与智能报告生成**，构建一个辅助医生完成「患者管理 → 病例管理 → MRI 影像查看 → AI 分析 → 风险评估 → 报告生成 → 医生反馈确认」完整闭环的平台。

## 二、项目定位

- **定位**：教学科研型医疗 AI 辅助诊疗平台
- **不是**：临床诊断系统 / 医院 PACS 系统 / 商业医疗软件
- **原则**：所有 AI 结果均为辅助参考，不替代医生判断

## 三、应用场景

1. 科研原型演示：脑胶质瘤多模态 AI 辅助诊疗流程展示
2. 教学演示：医学影像阅片（三视图 / 窗宽窗位 / 标注）教学
3. 算法验证底座：为真实分割模型（nnUNet / MedNeXt）与多模态融合模型提供可插拔接口
4. 竞赛 / 答辩 / 夏令营展示：完整的端到端医疗 AI 工作流

## 四、核心能力

| 模块 | 能力 |
|------|------|
| 病例 / 患者管理 | 增删改查、搜索、状态筛选 |
| MRI 影像阅片 | NIfTI 上传、三视图、真实窗宽窗位、Crosshair 同步、缩放平移 |
| 医生标注 | 点 / 矩形 ROI / 测距 / 角度 / 自由绘制 / 文字，五类标注，体素坐标，删除单个 / 全部 |
| AI 分析 | MRI 基线 + TabICL-v2 临床风险 + 多模态融合 + Agent 报告（接口可插拔） |
| 诊断报告 | AI 总结、推荐措施、医生意见、AI 结果确认闭环 |
| AI 分割叠加 | 模拟掩膜红色半透明叠加（预留真实模型接入） |

## 五、免责声明

> 本系统为「教学与原型工具」。所有 AI 分析结果仅供演示与科研参考，不构成临床诊断或治疗建议，最终判断请以具有执业资质的医生阅片意见为准。
