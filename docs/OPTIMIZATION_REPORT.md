# 系统优化与验收说明

更新：2026-10-06。所有项目编辑、缓存和实验产物位于 E 盘。

## 本轮改动与作用

1. 四序列上传先做空间与大小验证：3D、同 shape/affine、1 mm、正交，每序列最多 3200 万体素、512 MiB 文件。错误输入在更新当前 MRI 前拒绝，避免等到推理才发现几何不兼容；预览在线程池内生成，缩短数据库/任务提交锁。
2. MONAI 权重必须匹配固定 SHA256；ROI 只接受 16 的倍数且不超过 128，预算限制 256–6000 MB。现有默认 128×128×96、batch=1、CPU 拼接、低空闲显存走 CPU、OOM 单次 CPU 回退保留。
3. 元数据缓存最多 16 项，掩膜校验缓存最多 8 项，图像体数据缓存最多 2 项。键包含路径、修改时间和长度；实际文件变更重新校验。测试验证改坏 mask 会被拒绝，而不是命中旧成功缓存。
4. 前端各功能路由按需加载。入口 JS 从 1116.60 kB 降为 792.55 kB；gzip 从 362.81 kB 降为 251.71 kB。另有共享按需 chunk，不能把入口数字当全部页面流量。Element Plus/PDF 仍有大包警告，未宣称已完全解决。
5. pytest 在收集测试前设置唯一的 E 盘临时数据库，结束后只清理该次自有库，避免测试导入顺序误用开发数据库。
6. 启动脚本检查两个 HTTP 服务就绪，并阻止已有登记后端的重复启动；停止脚本用 PID+启动时间识别本次进程。已修正 PowerShell ISO 日期自动转换导致的停止误判，实际停机与重启通过。
7. 无验证模型的生存接口返回 503，病例页面提示尚未提供；不再显示旧硬编码的生存估计。研究概率仅在独立研究页显示，不冒充病例自动掩膜分类。

## 实测与验证

缓存基准对五例 FLAIR 与已保存预测掩膜，各调用元数据和掩膜验证 3 次。关闭对应函数缓存的重复调用合计 3.166518 秒；已有值的缓存调用合计 0.008704 秒。操作系统文件缓存为热状态，未包含网络、冷加载、切片渲染或 GPU，不能解读为整站加速 364 倍。

五例核心接口重新上传并推理成功，另验证重新分析；浏览器再次真实上传一例、执行推理、测距保存刷新、五例阅片与 PDF。五例 PyTorch 峰值分配均 505.23 MB，无 OOM/CPU 回退；该值不是全卡占用。WT Dice 仍为 4:0.789669、13:0.878183、16:0.936409、17:0.700217、19:0.862495；优化没有改变这些结果。三例参考 TC/ET 为空时假阳性仍保留登记。

研究 CPU 模型重载与服务重启后五例预测一致。细节见 STAGE_4_VALIDATION.md。前端生产构建、基础浏览器 2 项与专用真实数据浏览器验收通过；后端最终测试结果见 stage5/verification_summary.json。

证据：E:/BrainFusion-Runtime/results/stage5/cache_benchmark.json、persistence_validation.json；stage2/workflow_validation.json、stage3/browser_validation.json、stage4/api_validation.json/browser_validation.json。

## 仍有边界

当前任务执行器依赖单个后端进程；不支持多 worker/跨进程任务锁。没有自动配准、斜切重采样、成组 DICOM 或完整标注工具临床验收。Docker 未安装，配置增加了研究依赖和只读数据/研究目录，但未运行容器。FastAPI/Starlette 弃用和前端大包提示不影响已验证流程，后续统一升级时需要回归。

## 2026-10-07 自动特征优化

新增仅提取 20 个选中特征的隔离 CPU 工作器，避免改变主 CUDA/NumPy 环境。参考特征复现门槛绑定模型、协议、提取代码和版本来源；原空间 MRI 做经五例数值复现的全体积 min–max 缩放，使用发布的 binWidth=0.02。五例选中特征及原概率复现一致。

自动掩膜任务单 CPU worker、SimpleITK 2 线程；实际五例提取 1.982–3.667 秒。按输入/掩膜/临床/模型/协议缓存，相同请求直接读取成功结果，后台活动任务重复返回 409。分割页直接跳转到病例研究，页面轮询/刷新可恢复，重启保留已成功任务。原分割报告与确认未修改。

最新 26 项后端测试、2 项基础浏览器、构建、专用五例自动特征浏览器和实际重启验收通过，证据见 stage6。未重新训练、推理或占用 GPU。当前基准是工程耗时，自动掩膜输入仍需同协议队列重拟合与独立评估；隔离归档解释器正式部署前需升级复现。
