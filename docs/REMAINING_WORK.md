- **工程核心演示**：已达到可复现 RC 标准（病例、四序列 NIfTI、真实 SegResNet 单样本输出、掩膜、体积、版本化报告和 Edge 页面）。

- **论文实验准备**：可以开始方案和数据/伦理准备；将 UPENN 纳入实验前必须完成前述人工复核和授权条件。
