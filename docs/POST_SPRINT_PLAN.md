## GPU 与长任务实施规则

本轮只做预训练分割推理和 CPU 轻量拟合。后续不自动开启完整三维训练。确需训练时先用一例、batch=1、固定 patch 跑短测，记录 nvidia-smi 全卡占用与 PyTorch 峰值、单步耗时；检查温度、E 盘空间和中断恢复，再按实测推算总时间。

例如预计训练时间 = 实测单步秒数 × 总步数 / 3600；加数据加载与验证开销。没有短测记录时不写“训练两小时”这类确定值。显存预算维持不超过 6000 MB；出现 OOM 先停止并保留错误，缩 patch/CPU 输出或降低任务规模，不能并发加大批次。
