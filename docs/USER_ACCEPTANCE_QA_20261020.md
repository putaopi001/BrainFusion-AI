### Q4：公开的胶质瘤 DICOM 数据能否用于后续工程验收？

目前优先候选是 TCIA UPENN-GBM。官方集合页列出 DICOM、630 名受试者、3,301 个检查、3,680 个序列，页面标注 CC BY 4.0；DICOM 约 139.4 GB。该队列论文说明有 T1、增强 T1、T2、FLAIR 等结构 MRI。但这不能证明任意一位患者的原始 DICOM 在同一个 Study 中具备本系统要求的四个角色，也不能证明几何共同空间条件已满足。操作与数据决策清单见随包交付的[独立维护手册第8节](INDEPENDENT_MAINTENANCE_GUIDE.md)；完整候选评估留在工作区 `docs/PUBLIC_GLIOMA_DATA_RECOMMENDATION_20261020.md`。

主体工程完成后，建议按以下顺序决定是否使用：

1. 只从少数目标检查/序列生成 manifest，不全量下载；保存 manifest、数据引用和下载校验记录。TCIA 当前下载流程正从旧 NBIA 向新的 Data Retriever / NCI Imaging Data Commons 迁移，按当时官方说明操作。

4. 只有上述条件都通过，才在隔离副本上做像素读取、转换、导入及页面链路验收。该数据可用于影像工程链路，不因此自动成为 IDH 模型训练/临床效能证据。
