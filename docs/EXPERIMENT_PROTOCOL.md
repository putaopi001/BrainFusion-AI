# 实验协议（实施前冻结）

版本：草案 0.1，2026-10-03。研究假设均待验证，不能预先声称 TOPSIS 有提升。终点、队列和权重来源确定后填写配置并冻结。

2026-10-06 更新：当前轻量工程原型的具体协议与结果在 STAGE_4_VALIDATION.md。它使用等准则权重 TOPSIS 和同构逻辑模型，不代表下文熵权/动态融合及完整联邦对照已完成；已查看的 22 人拆分全部标为探索性。正式研究先另行冻结协议，不能按原型测试结果调参后继续声称独立测试。真实分割当前是 MONAI BraTS SegResNet。

## 分割实验

- 主模型：一份兼容 nnU-Net v2 权重；MedNeXt 仅在首模型完成且资源允许时加入。
- 指标：所选数据版本定义的 WT/TC/ET Dice、HD95（mm），区域体积误差、耗时、峰值显存、失败率。逐病例记录，mask 在同一物理空间比较。
- 两者都空：Dice 按约定记 1 并单列数量；单边空：Dice=0；HD95 空区域记未定义，单列数量，不能用过滤提高汇总表现。最终遵循所用官方评估规则并注明差异。
- 公布样本量、成功/失败、均值/中位数/分布和患者级置信区间；失败不从总分母隐去。

## 预测与融合实验

启动条件：确定同一临床终点及标签、患者、模态对应关系，所有分支输出同一事件概率。分割 mask/分割置信度不能直接充当肿瘤分型概率。

基线：临床 Logistic Regression；真实 mask 影像组学分类；资源允许的影像分类。候选 XGBoost/TabM/TabICL 只选择必要对照，不强制齐全。

融合比较：单模态、简单平均、验证集确定的固定权重、EWM-TOPSIS。消融包含具备数据的各模态组合；只有两模态时不虚构三模态消融。

主指标按终点确定（候选 ROC-AUC）；附 PR-AUC、敏感度/特异度、F1、Brier、校准曲线。分类阈值在验证集冻结，不能用测试集最优阈值。

## TOPSIS 的定义边界

明确方案（模型/客户端）、准则、收益/成本方向、归一化、熵权拟合样本、理想点、距离与权重变换。贴近度不等于概率，转换为非负和为 1 的权重后才能融合。

固定权重：按开发验证指标估计并冻结。

患者级动态权重：只能使用推理时可见的缺失模态、质量检查、校准后的不确定性或模型分歧等；准则归一化和权重在开发数据拟合。该患者的 AUC/F1、真实误差不可作为输入。若可靠性代理无证据，则作为探索性方法而非确认性结论。

必须定义全零距离、常量准则、零熵/零权重、NaN、缺模态、并列、极小样本的 fallback（如可用模型均匀权重），保存触发原因。参数稳定性、准则删除和权重敏感性为必做消融。

## 联邦实验

第一轮联邦对象为固定特征上的同构小型神经网络；集中式和各联邦方法使用相同结构与初始化策略。冻结的分割/特征提取阶段不计作联邦训练。Logistic/XGBoost/TabICL 不与该网络做参数平均。

对照：Centralized、Local-only、FedAvg、FedProx、EWM-TOPSIS-Fed。IID 和至少一个 Non-IID 场景，初始 3 个种子，报告探索性样本限制；若结果不稳定扩大重复次数，不能只选最好种子。

统一每轮客户端参与率、本地 epoch、优化器、批量、轮数/计算预算和早停规则。超参数仅在开发数据选择。记录每轮各客户端权重、指标、通信字节、耗时、最差中心表现。

TOPSIS-Fed 评价方案在实现前二选一并固定：

1. 所有客户端候选在统一的非测试参考验证集评价，所有对照允许相同访问；披露该额外参考数据假设。
2. 客户端本地留出验证，预定义样本量/不确定性修正；披露跨中心分布导致分数不可直接比较的限制。

不得用最终 test 评价每轮客户端。用同一验证集逐轮选权重会产生适应性过拟合，应在最终独立 test 检验。聚合非参数 buffer、客户端掉线、单类别指标失效和异常权重均需定义处理规则。此模拟不提供差分隐私或真实医院安全保证。

## 解释、统计与复现

- 按模型选择一种适合解释；SHAP 用训练参考背景，Grad-CAM 仅用于适配的可微影像网络。解释图不等于因果证据。
- 校准在 validation 拟合；模型分歧与概率熵不能未经验证标为临床置信度。
- 比较使用相同患者配对分析和 bootstrap 区间；多种子变异与患者变异分别报告，主要比较预先确定，探索性多重比较注明。
- 模拟中心留出不能自动视为外部验证；没有真实外部队列时明确写“独立留出评估”。

每个 run 保存代码 SHA、环境、输入/划分哈希、权重哈希、配置、种子、患者级结果、汇总、日志与失败原因。产物按 segmentation/multimodal/topsis/federated/ablation/xai/figures 分类，生成路径可重定位。

## 运行顺序

少量合成指标校验 → 2–5 病例通路 → 开发集基线 → 验证集方法/消融 → 12/15 锁定 → 12/16–12/24 最终留出评估。之后修改方法需注明新版本，不反复在同一测试集调参。
