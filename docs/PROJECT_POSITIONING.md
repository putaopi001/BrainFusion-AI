# BrainFusion AI 项目整体定位

## 一、一句话定位

BrainFusion AI 是一个融合医学影像处理、深度学习辅助分析、临床知识增强和医生交互反馈机制的脑胶质瘤 AI 辅助诊疗原型系统，旨在构建从 MRI 影像阅片、AI 肿瘤分析、风险预测到辅助诊断报告生成的一体化智能医疗平台。

## 二、核心定位（不是简单的 MRI Viewer）

MRI Viewer 只是「医生与 AI 模型交互的核心入口」，真正定位是完整闭环：

```text
医学影像 → 智能分析 → 临床辅助决策 → 医生确认反馈 → 诊断报告生成
```

## 三、系统整体架构

```text
BrainFusion AI
├─ 前端交互层  Vue3 + Element Plus（医生工作站）
├─ 后端服务层  FastAPI + SQLAlchemy + SQLite/PostgreSQL
├─ 数据管理层  MRI 数据 / 病例数据 / 标注数据 / AI 结果
└─ 智能分析层  MRI 分割 / 风险预测 / 报告生成（AI 预留）
```

## 四、核心模块定位

1. **病例管理模块** — 医疗数据生命周期管理中心（患者/病例/MRI/AI 记录/报告）✅ 已完成
2. **MRI 智能阅片工作站** — 医生查看、分析、标注医学影像的核心交互平台（当前重点）
3. **AI 分析模块** — 医学影像智能理解引擎（接口已就绪，模型未接入）
4. **临床决策模块** — 从 AI 结果到临床建议的桥梁（风险等级/建议/报告）
5. **医生反馈闭环** — 区别于普通 AI Demo 的关键（AI 预测 → 医生确认/修改 → 保存意见）

## 五、当前阶段（v0.1）

属于「医疗 AI 原型系统工程化阶段」，完成度约 60%：后端 FastAPI/数据库/病例流程/MRI 上传预览/API 规范化/Docker/测试 ✅；前端 Vue3/页面体系/病例详情/Dashboard/MRI Viewer ✅；AI 接口完成、模型未接入。

## 六、阶段收工标准（MRI Viewer v1.0）

1. MRI 状态正确（处理中 → 阅片就绪 → AI 分析完成）
2. 三视图稳定（Axial / Coronal / Sagittal 全部正常）
3. 鼠标交互（左键拖动、滚轮切片、右键调窗、放大缩小）
4. 标注闭环（画框 → 保存 → 刷新 → 重新显示）
5. AI 结果融合入口（MRI + Mask + AI 概率）
6. 页面美化（医疗软件感觉，非普通后台）

## 七、最终愿景

```text
患者 MRI → AI 自动分析 → 肿瘤分割 → 分子预测 → 生存预测 → 知识增强报告 → 医生确认 → 辅助治疗决策
```

长期目标：面向脑胶质瘤患者的多模态智能辅助诊疗平台。
