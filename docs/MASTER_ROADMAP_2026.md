# BrainFusion AI 2026 年底执行路线

基准日：2026-10-03。内部功能截止：2026-12-15；最终交付：2026-12-31。10 月 3 日到 12 月 31 日相差 89 天，含起止日为 90 个日历日。

## 目标与依据

交付 v1.0 Research Edition：真实分割、同一任务的多模态预测、EWM-TOPSIS 融合、模拟多中心联邦实验、解释与报告、可复现软件及实验材料。本文根据用户粘贴的历史讨论和本地代码制定；粘贴内容属于规划提案，不证明模型、数据和实验已完成。

代码基线为 d1bc7a0；最初核查见 EXECUTION_PLAN.md。截至 2026-10-06，真实 MONAI 分割主闭环与 CPU IDH/融合/模拟联邦原型已通过本机验收，具体状态见 CURRENT_STAGE.md。本文是全年路线，不能把原型当正式实验完成，也不能沿用文档里的“60%”作为整体完成率。下一阶段具体步骤与工时以 POST_SPRINT_PLAN.md 为准。

## 最短可行技术路线

1. 先用一份来源明确、与数据匹配的 nnU-Net v2 权重完成真实分割；已有其他可运行权重时按实际成本调整。MedNeXt 为备选对照。
2. 从真实 mask 提取区域体积/影像组学。按数据条件选择一个预测终点，所有预测分支使用同一患者、同一标签和同一预测时点。
3. 先完成 Logistic Regression 与一个可训练的小型神经网络基线，再按资源选择 XGBoost、TabM 或 TabICL；不要求全部接入。
4. 先比较单模态、简单平均、固定权重，再实现 TOPSIS。患者级可靠性只能用推理时可获得的信息，不能用该患者真实标签或测试集性能。
5. 第一版联邦学习固定同构小模型、固定预提取特征，在 3–4 个虚拟中心比较 Local/Centralized/FedAvg/FedProx/TOPSIS-Fed；不在年底前联邦训练完整分割网络。不同结构的模型不能直接平均参数。
6. 仅将实验中验证过的能力接入报告，所有模拟中心、占位输出和研究限制显式标明。

## 降级与止损

- 10/09 没有可用权重/数据：先跑合法取得的少量样本，延期模型承诺；不把随机初始化网络当真实能力。
- 10/25 分割未完成：停 MedNeXt 对照和新 UI，优先完成一个模型闭环。
- 11/08 无同患者临床标签：放弃当期临床融合，改成影像/影像组学单任务；明确不满足完整多模态 v1.0，不制造临床数据。
- 11/20 患者级权重无法无泄漏定义：先交验证集确定的全局 TOPSIS 权重，动态患者级融合延期。
- 12/05 TOPSIS-Fed 未稳定：保留 FedAvg/FedProx 和失败分析；不宣称创新优于基线。
- 12/15 仍有核心缺口：宣布降级 Research Release，把缺口列入 release；12/16 后不补新模型。

时间优先级：数据/标签正确性 → 坐标与模型可运行 → 对照评估 → 系统闭环 → 解释/展示。任何负结果都允许交付，但不能替代缺失实验。

## Git 检查点

实现阶段使用 codex/ 前缀分支，小批次提交；每阶段提交包含代码、适当测试、配置与证据。建议阶段标签 v0.1.1、v0.2.0-seg、v0.3.0-features、v0.4.0-fusion、v0.5.0-fed、v0.9.0-rc、v1.0.0；仅在对应验收完成后创建，不以日期冒充完成。本文不创建标签或推送。
