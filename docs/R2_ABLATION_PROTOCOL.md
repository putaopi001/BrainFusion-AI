# R2 敏感性与缺模态消融补充协议 v1

2026-10-16，接续R2_ENTROPY_PROTOCOL.md；本文件先于本轮实现/计算冻结。已有22人和上轮结果已被观察，本补充是事后描述性诊断，不是预注册独立评价，不据网格最好值选择部署权重。原熵权定义/阈值0.5、原98/21/22角色与源文件不变。仅重用上轮逐患者概率和验证准则，禁止重训练、重分、用评价标签拟合熵权或修改产品模型/latest。

验证侧敏感性：仅从原冻结验证指标矩阵生成基线1种、每次弃用一列3种、每次单分支单指标加/减0.01、0.05、0.10共36种，总40种。加减后按已知[0,1]界限截断并记录实际差值，缺失NaN保留；每种拟合名单仍是21验证人。先保存全部变体状态/SHA，再读本轮评价标签/计算指标。输出准则/分支权重、相对基线L1与最大绝对差、并列最优分支及回退。不用40个变体作为40个独立患者，不根据评价结果选变体。

全局分支权重敏感性：固定临床权重0、0.05、…、1（21点），影像组学=1-临床。仅在原完整22人上作描述性曲线数据，列出全部结果/每人概率，不择最好更新模型/论文，不作为校准或阈值选择。熵权准则本身不手工调权；此处是最终融合分支权重的诊断。

缺模态场景固定为complete、clinical_missing、radiomics_missing、alternating_single_missing、one_all_missing、all_missing六种。交替和单例全缺由患者ID字典序排序位置确定：交替偶数位置缺临床、奇数位置缺影像组学，单例全缺是字典序最前患者；不读取标签/概率决定缺失，不代表真实缺失率。六方法为临床、参考掩膜影像组学、平均、原固定0.6/0.4、原等准则TOPSIS、原熵权TOPSIS。所有方法保留同一22患者总分母；单分支基线只允许自己的分支，不能借另一分支仍称单分支成功；四种融合允许两分支。基线与融合分别披露可用信息。

可用且被允许的分支上归一化原固定权重；可用权重总和≤1e-12时在可用且允许分支均匀回退并记录。全部允许分支缺失返回逐患者failed/null，不填0.5、不伪造成功、不删总分母。原生产熵权API仍按整批全缺拒绝；离线评估按行调用核可成功患者，以保留每个失败。记录每方法/场景的22总数、成功/失败及ID、每人观测缺失/允许分支/有效权重/原因。只对成功患者计算条件指标，明确不是全22人性能；AUC与平衡准确率在少于两类别时记null并给原因，Brier只需有成功患者，无成功则全部指标null。部分失败不能拿条件指标与完整22人作直接优劣结论。

来源：配置冻结上轮comparison.json、entropy-state.json、predictions.csv及原熵协议SHA；运行时重核comparison列出的原输入/源码SHA，核state内部一致性和SHA、预测身份/原逐患者标签/两个概率、已观察角色、六方法原值。输出配置/源SHA、40状态、21权重点与36方法场景完整逐患者记录；源产物/活服务/正式库不改。结果是参考掩膜和原始idh1/2=1工程诊断，临床极性、预训练重叠和同协议自动掩膜队列仍未解决。动态质量权重延期。
