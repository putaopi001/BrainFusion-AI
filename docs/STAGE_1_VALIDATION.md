# 第一阶段说明：真实数据与分割模型

完成日期：2026-10-04。验收通过。

使用 WAW-GliomAI v3 五个术前患者、每人四序列。模型是官方 MONAI BraTS SegResNet，固定版本 370f7f9d062745fbac445e7fe6d6616d35df04ec；不是 nnU-Net。权重与数据 SHA256 留档。原始影像与参考掩膜位于 E:/BrainFusion-Data，模型与运行结果位于 E:/BrainFusion-Runtime。

实现四序列归一化、LPS 方向转换、单窗口滑窗推理、CPU 输出拼接和原 affine 恢复。CUDA 批量为 1，默认预算 6000 MB，OOM 单次 CPU 重试。峰值是 PyTorch 分配量，不等于整个显卡占用。本阶段无训练、无 OOM。

## 实际准确性限制

患者 4、16、17 的参考掩膜 TC/ET 体积为零，但模型输出非零体积，所以这些区域 Dice=0，HD95 按单侧为空规则记录 null。没有把这种情况归为完全正确，也未删除低指标样本。预训练 BraTS 模型在本数据集有假阳性与分布差异，后续需要校准/微调与独立队列验证。
