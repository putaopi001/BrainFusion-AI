# P3显式重采样工程验证记录（2026-10-18）

## 决策范围

已选择在用户明确勾选后，允许以T1增强（T1c）为参考，在同一Study、同一FrameOfReference下使用物理坐标identity mapping和线性插值生成1 mm各向同性目标网格。方案会保存重采样策略、每个源序列网格、输出目标网格、插值参数、体素对照哈希和误差。默认仍是严格原网格检查。

本决定仅授权纯影像工程验收，不授权把重采样序列激活为模型输入、触发推理，或作为胶质瘤预测效能证据。特别是6.5 mm层间距插值到1 mm只增加采样点，不恢复原始采集中不存在的层面细节。

## ACRIN-134真实DICOM尝试

样本来自TCIA ACRIN-NSCLC-FDG-PET公开集合（CC BY 3.0，DOI `10.7937/tcia.2019.30ilqfcl`）。这是肺癌队列的脑MRI样本，只用于工程链路候选，不是胶质瘤队列。

离线元数据核验得到同一Study下T1增强、T1、T2 FSE、FLAIR各26层，均为MR、同一FrameOfReference、原始未压缩Little Endian；矩阵/像素间距为前三序列256×256/0.859375 mm，T2为512×512/0.4296875 mm；四序列实测层间距均为6.5 mm。重采样方案构造目标网格220×220×163、1 mm，几何覆盖检查通过。

在真实转换阶段，系统按原有像素审核门槛拒绝：四条序列抽查的原文件均没有`BurnedInAnnotation=NO`声明，首文件返回`pixel_review_unresolved`。没有改写或补写DICOM头、没有生成NIfTI、没有登记转换版本、没有导入/激活/推理，也没有写业务数据库。原始候选仍在隔离的数据目录；本次方案/快照/失败回执仅在`E:/BrainFusion-Runtime/results/nightly/2026-10-18/`下。

已生成四张仅含匿名切片编号的全序列缩略检查图（每序列26层）。初步目视没有发现明显烧录文字，但这不替代用户对104层的人工确认，因此没有解除像素审核状态。文件位于`E:/BrainFusion-Runtime/results/nightly/2026-10-18/acrin134_pixel_review_v2/`。

## 验收结论与下一步

代码层显式重采样路径及模型激活隔离已通过定向测试；ACRIN-134的真实元数据几何规划通过，但真实像素转换未通过，因为来源文件缺少当前要求的无烧录声明。故不能把这次尝试记作真实DICOM→NIfTI转换成功，也不能声称P3真实四序列闭环完成。

解除该项需要对候选图像执行并留存独立人工像素烧录检查，且不能靠修改原DICOM元数据绕过校验；或者改用明确声明`BurnedInAnnotation=NO`且许可合适的公开病例。之后还要按网页流程检查来源、捕获原文件、转换、重新打开完整性复核、审核角色声明，并保持激活/推理关闭。角色映射当前依据序列描述暂列，尚未由临床阅片者复核。
