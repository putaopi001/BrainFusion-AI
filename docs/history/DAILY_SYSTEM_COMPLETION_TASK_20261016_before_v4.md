### E. 第二阶段：原规划研究任务

R1 数据与模型：查官方数据说明、标签字典、同患者多检查及 MONAI 预训练来源，记录仍未解决的事实。公开可直接取得的数据自动下载校验；需要申请/登录的数据不要假装取得，不自动联系发布者。先估磁盘和传输量，分批扩充 10–20 例做批处理验证，再依冻结协议处理可用训练队列；十几例不能作为充分统计样本的保证。冻结队列角色后同协议提取参考/自动特征、比较缺失漂移，训练内拟合插补/标准化/选择与分类，验证选阈值/校准，保存新模型和来源。当前 22 人已观察拆分保持探索性，不通过随机重分恢复独立测试身份。

R2 融合：平均、固定、全局 TOPSIS、熵权 TOPSIS 采用同患者、同终点、同允许信息；明确收益/成本、归一化、熵权拟合来源及常量/NaN/缺模态/并列/极端权重回退。保留负结果，不保证新方法优于基线。患者动态权重没有可靠代理证据时延期，不用真实 Dice 或患者标签生成部署权重。

R3 联邦：统一同构小模型、患者划分、初始化与计算预算，比较 Centralized、Local-only、FedAvg、FedProx、TOPSIS 聚合；IID 与预定义 Non-IID，至少三个预先指定种子。记录每中心及最差中心、每轮权重、耗时和通信估算方法；本地单类别 AUC 无法计算时按冻结规则处理。集中预处理和公共验证池假设披露，不宣称真实跨院或隐私保证。

R4 统计与解释：预先确定主指标/比较，报告患者级区间、校准/Brier、敏感度/特异度、分割空区域和全部失败。种子/交叉验证折不当作独立患者。解释选择适配实际模型的方法；不能把系数或 SHAP 写成因果关系，也不能给当前表格模型虚构 Grad-CAM。外部评价只有来源、重叠和角色核查完成后执行；未取得外部数据就报告真实限制。

- 训练/下载/推理长任务记录 PID、启动时间、配置、日志和输出目录，可中断恢复；下一轮检查已完成或仍运行后决定续接。后台 helper 隐藏窗口。
- 在副本或隔离测试数据库验证迁移；递归移动/删除之前核对绝对目标范围，不对未知用户数据做清理。
- 不自动付费、推送、发布、发送消息给别人或改动本轮以外的项目。不在普通实现选择上反复求确认；确需账号、提权、重启、范围取舍或关键标签解释时清楚说明。

### G. 单轮工作节奏与失败处理

每轮优先完成一个可验收小批次；成功后继续下一项，不为了凑一小时增加改动或重复检查。不编写只重复实现的低价值测试；选择能验证真实行为、数据一致性和空间正确性的检查。

每批按“读相关代码 → 实施 → 必要验证 → 保存证据 → 更新状态”推进。只有验收满足才标已验收；验证失败保留输出和原因。浏览器能力不可用时记录为待浏览器验收，继续接口与独立工程，不用接口通过冒充浏览器通过。

同一问题两次尝试无进展就改变排查策略，优先读取日志、缩小复现和查官方资料；仍需外部条件则标受阻、给出下一步和解除条件，转做独立任务。不得每小时重复同一下载、安装或测试失败。修复影响已通过项才扩大回归。

不要硬性要求单轮必须满一小时，也不要保证八小时不中断。结束前保存可以直接续接的交接；被中断后下一轮核对工作区和运行任务再继续。

### H. 证据、日报与用户抽查

证据写入 E:/BrainFusion-Runtime/results/nightly/YYYY-MM-DD/run_id/，同名结果不覆盖；保存必要日志、配置、摘要和截图，避免输出隐私或敏感凭据。日期按北京时间。

每轮更新系统清单、交接和 docs/CURRENT_STAGE.md，只更新实际发生的内容。写入或追加 docs/daily/YYYY-MM-DD.md；跨午夜先归档本轮日期，并注明用户抽查对应哪个夜间窗口，不因日期变化丢失上一晚摘要。

每轮结束输出：
1. 本轮任务编号与实际完成行为。
2. 验证结果及证据位置；未验证项明确列出。
3. 仍运行的长任务、阻塞与是否需要用户动作。
4. 用户抽查步骤，最多五项：实际地址/页面、输入、操作、预期结果。已能提供页面截图时保存截图。
5. 下一轮可直接执行的第一步。

每天汇总一次：新增验收任务、修复问题、剩余任务按编号列出、数据/环境状态、实际耗时与下次优先项。没有重要变化的重叠触发不反复发长日报。

用户白天反馈一旦到达，在下一轮优先处理。每两至三晚按已验收任务和剩余复杂度修订工期；以任务验收计进度，不以代码行数、运行时长、页面数量或旧文档完成百分比计进度。先前 3–5 周是初步规划，不承诺为了按期而跳过验证。

### I. 停止与完成条件

第一阶段全部 P1–P4及F/E交付项通过后单独报告系统交付完成并进入已授权的第二阶段；第二阶段所有可完成 R 项验收且材料齐备后报告原规划完成。受阻项必须明确披露，不能靠标延期来冒称完整研究版完成。

全部批准范围完成后不再改代码、不反复训练，通知用户关闭或调整定时任务。有定时管理工具时按当前授权与工具规则处理，否则仅报告未停用，不假称关闭成功。仅提示词文件更新不等于定时任务启用。
