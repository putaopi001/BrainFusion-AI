## 推荐的候选主线

工作题目：**自动分割不可靠时，质量感知的临床—影像组学融合能否维持胶质瘤 IDH 预测的可靠性？**

这是待检验方向，不是已确认原创的方法。第 1–2 周必须补查质量感知融合、选择性预测、空子区与缺失区域处理的近邻工作；若没有可清楚界定的差异，应转成严谨的跨队列基准研究或重新定位，不能仅改名称。

核心范围只保留一个临床终点、一套冻结分割器、轻量分类模型与一个可靠性机制。阅片/报告系统作为运行与复现载体。暂停把联邦、双分割网络、生成式报告、生存预测、Ki-67 和完整新 UI 纳入本篇的必要交付。

可检验机制：用推理时可得的区域存在性、跨扰动预测稳定性、特征缺失及分布异常等质量代理，决定减弱影像分支或转为临床基线/人工复核。没有参考掩膜时不能使用该患者真实 Dice，不能使用 IDH 真值或最终测试性能选择权重。质量代理不自动等于真实分割准确率，必须在开发数据检验关联；自然不存在的区域不等于分割失败。

最低对照：临床基线、参考掩膜影像组学、自动掩膜影像组学、简单平均、开发数据拟合的固定融合、简单质量阈值回退、候选质量感知融合。若保留 TOPSIS，加入全局 TOPSIS 并说明相对简单回退的必要性，不以更复杂为贡献。

参考/自动掩膜在完全相同患者及提取协议下比较；训练内完成插补、标准化、特征选择、校准和规则拟合。可以比较参考特征训练→自动特征评价的迁移损失，以及自动特征训练→自动特征评价的改善，避免把提取协议不同混同为分割误差。

评价至少覆盖患者级 AUC、Brier、校准、敏感度/特异度及配对区间；报告空区域、缺失、提取失败和低质量病例，不能删除后改善汇总结果。若拒绝输出，必须报告覆盖率与剩余病例风险，防止以少输出换高指标。预先选择一个主比较；重复交叉验证各折和多种子不能当作互相独立的新患者。

外部队列优先考察 UCSF-PDGM，官方集合提供 MRI、分割及 IDH。原论文描述 501 例，当前集合检索显示 495 位患者/501 次检查，必须按选用版本确认并以患者去重。它与 BraTS 的来源映射、分割 checkpoint 的训练来源需审核，不自动视作独立外部队列。EGD 可作为另一个候选，但本次未完成其当前访问条件与标签覆盖核查。

## 10–12 周工作安排

每天 2–3 小时约为每周 14–21 小时，12 周约 168–252 小时。下面是规划估计，不是实测保证；数据申请、传输和审稿等待另计。

| 周次 | 优先交付 | 止损条件 |
|---|---|---|
| 1–2 | 标签/区域语义、预训练重叠、外部数据可用性、最近邻文献表及冻结协议 | 两周内没有可检验差异或可信评价路径，停止扩展平台并重定题 |
| 3–4 | 开发队列自动 mask、成对同协议特征、缺失及漂移表 | 保留失败；不为了跑通更换标签或删差病例 |
| 5–6 | 轻量基线、质量代理验证、简单回退与候选方法 | 没有稳定信号则转成失败/鲁棒性基准，重新判断投稿价值 |
| 7–8 | 锁定对照/消融、内部重采样、校准与开发统计 | 不根据外部测试表现挑方案 |
| 9–10 | 冻结后的外部评价、患者级区间、图表与初稿 | 精度不足就收窄结论，不夸大优越性 |
| 11–12 | 导师审阅、复现检查、补充材料与投稿 | 按最终证据和期刊范围选刊，不以承诺快录用选刊 |

若年底前需要尽快进入审稿，应争取 11 月底至 12 月上旬提交；从第一周同步写方法和数据记录，不能等软件年底发布后才启动写作。若核心证据需要完整 12 周才齐备，应优先保证有效性并接受年底投稿目标可能顺延。
