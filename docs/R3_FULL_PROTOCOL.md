# R3 完整轻量联邦模拟协议 v1

2026-10-16，先于本轮实施/训练冻结。范围为本机CPU、发布者参考掩膜固定表格特征、已有141患者98训练/21公共验证/22已观察探索评价，五工程患者排除。原始事件idh1/2=1的临床极性仍未知；不重分获取独立性、不称真实跨院/隐私保证，不改正式模型/latest/UI/论文结论。完整同协议自动掩膜队列与独立评价仍属R1/R4。

## 模型、预处理和公平预算

采用当前实际同构逻辑模型（22变换特征+截距，float64），而非旧草案中未实现的小神经网络；符合当前用户“统一同构小模型”的范围，保留既有梯度/聚合实现与旧simulate不改。临床age/female；影像组学仅原CSV original_特征，区域1/2/3。只在98训练患者拟合中位数插补（保留空列）、StandardScaler与训练F检验选20影像特征，再与2临床/截距组合。公共集中预处理供全部方法相同使用；不是联邦特征选择或私有数据系统。

种子固定20261016、20261017、20261018，场景iid与label_skew，共6个运行条件。每条件六方法：centralized、local_only、fedavg、fedprox、validation_topsis、validation_entropy_topsis。所有方法同一个种子生成N(0,0.01²)初值，包括截距；场景不改变同种子的初值。20轮，每轮本地全批梯度5步，学习率0.05、L2=0.01（截距不L2），FedProx mu=0.1且锚点本轮输入全局参数（包括截距）。不早停、不调超参、不选最好种子。主描述比较FedProx vs FedAvg的同条件患者AUC；熵权vs FedAvg为次要，所有方法/负结果完整保留，统计推断另归R4。

每方法总样本梯度计算预算均20×5×98：Centralized每轮对全部98做5步；Local-only三个模型各自只对所在训练中心每轮5步且从自己上一轮继续；四联邦方法每轮100%三个中心从同一全局参数做5步后聚合。Local-only不平均模型，每个评价患者用其身份分配中心的对应模型；Centralized与联邦为单一全局参数。验证评价调用次数/额外近端计算/通信开销并不相同，记录并披露，不把相同梯度预算称完全相同墙钟计算。

## 模拟中心与可用信息

训练中心仅由98训练集生成：iid按标签分层、同seed打散后分三份；label_skew沿用现有稳定按训练标签排序再三等份，非真实医院，允许单类别训练中心。验证/评价中心不看其标签：SHA256(f'{seed}:{patient_id}')前8字节按big-endian整数模3，同种子在两个场景相同。该设计仅模拟训练标签偏斜，不宣称验证/评价中心具备同样标签偏斜或真实外部中心分布。

TOPSIS两种方案每轮候选均在共同21人验证池计算AUC/阈值0.5的平衡准确率/Brier，收益/收益/成本。所有方法可访问同一公共池；FedAvg/FedProx记录候选质量但仅按训练人数聚合。旧TOPSIS为原向量归一化等准则权重，熵权复用已冻结R2定义；无测试评价参与训练/每轮权重或超参。训练API只接收train/validation矩阵和标签，评价矩阵/标签在全部36次方法拟合、模型/初值/轮迹写盘并哈希冻结后才用于评价。逐轮反复公共验证可能适应性过拟合，22人已观察不能充当独立最终检验。

FedAvg/FedProx权重为中心训练人数/98。TOPSIS若某准则非有限/未定义则所有候选共同弃用该列，剩余收益/成本保持；无可用准则时均匀。常量/零距离/熵退化按原R2/旧TOPSIS规则保留明确原因。熵状态按client_0/1/2身份与验证名单记录。无患者标签/真实Dice作部署动态权重。候选非有限、错维、空/重叠中心、源角色不符应具体失败，不能静默丢中心或提高分母表现。v1全参与不模拟掉线；无非参数buffer，不能外推神经网络buffer处理。

## 指标、时间与通信

每条件每方法完整22患者概率/标签/模拟中心、总体及三中心AUC/平衡准确率/Brier、成功/失败/总数。少于两类别则AUC/平衡准确率null并说明；零人中心全指标null且保留。最差中心AUC/平衡准确率只在有定义中心取min、Brier取max，同时给有定义/未定义中心数量与每中心样本数，不能把忽略未定义中心说完整最差中心评估。种子/中心/轮数不是独立患者。

每轮记录本地更新各中心耗时、公共验证耗时、聚合耗时、全轮耗时、实际步数/样本梯度数、聚合权重和候选验证三指标；Centralized/Local-only没有聚合权重则明确null。保存拟合和评价分别的墙钟耗时、Python/NumPy/sklearn/BLAS线程配置与PID。

通信是参数负载估算，不发生真实联网：每联邦轮对每中心发全局向量并收候选向量，float64字节=参数数×8，三个中心各上下行一次；20轮/23参数时每联邦方法22,080 bytes，每中心7,360。Centralized/Local-only为0参数聚合通信。排除初始数据/集中预处理共享、公共验证池、控制协议/加密/网络重传和硬件，因此不是测得真实网络流量或隐私保证。
