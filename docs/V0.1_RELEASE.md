# BrainFusion AI v0.1 — 发布说明

版本：v0.1.0
定位：教学科研型医疗 AI 辅助诊疗平台

## 一、完成内容

### 后端
- 数据库模型：Patient / Case / MRI / Prediction / Report / MRIAnnotation / DoctorOpinion
- REST API：病例、患者、MRI、标注、预测、报告、医生意见、预处理、调试
- 统一响应格式 `{code, message, data}` + 统一异常处理（404/422/500）
- 日志系统（core/logging.py）、配置管理（core/config.py）
- AI 模块接口抽象（ai/interfaces.py：BasePredictor / BaseSegmenter + 注册表）
- MRI 状态机：uploaded → processing → preview_ready → analyzed → doctor_verified / failed
- 体素元数据端点（shape/spacing/min/max）、真实窗宽窗位切片渲染端点、分割掩膜端点、探针体素值端点（/voxel）
- 分割掩膜上传/保存端点（POST /segmentation，含形状校验）
- 影像组学特征提取（强度/形态/纹理熵）+ 启发式生存预测（/radiomics、/survival）
- 时间戳补齐（created_time / updated_time）+ 守卫式 schema 迁移
- 依赖拆分（requirements-core.txt 与重型 AI 依赖解耦）

### 前端
- 医疗风布局：Sidebar + Header + Main
- Dashboard 工作台（统计 + 诊疗流程）
- 病例 / 患者管理页面
- 病例详情页（病例/患者/MRI/AI 结果/报告/医生意见）
- MRI 阅片工作站（组件化：MRIViewer/Toolbar/Viewport/AnnotationLayer/SliceController/WindowLevel）
- 真实窗宽窗位（体素强度 LUT）、三视图 Crosshair 同步、缩放平移
- 标注系统：点/矩形·椭圆·圆形 ROI/测距/双向测量/角度/自由绘制/探针/文字，五类标注自动配色，体素坐标，删除单个/全部
- AI 分割叠加（模拟掩膜）
- **Cornerstone3D 高级渲染模式**（客户端 GPU 三视图 MPR + 十字线 + 3D 分割编辑（笔刷/矩形·圆形·球剪刀/填充/显示切换），Canvas 为默认回退，懒加载）
- **PDF 诊断报告导出**（html2pdf.js 懒加载，中文支持）
- **影像组学 + 生存预测展示**
- Pinia 状态管理（case/mri/ai/report）

### 部署与文档
- Dockerfile（backend/frontend）+ docker-compose.yml + nginx.conf
- 测试：pytest 接口测试
- 文档：README + PROJECT_OVERVIEW + SYSTEM_ARCHITECTURE + ARCHITECTURE + V0.1_RELEASE + FUTURE_PLAN

## 二、测试结果

- 后端 `pytest tests -v`：**6 passed**（root / debug / 病例创建 / 病例列表 / 统一 404 / 删除全部标注）
- 前端 `npm run build`：**构建成功**
- 接口冒烟：`/`、`/debug/system`、`/patients/`、`/cases/`、`/mri/{id}`、标注 CRUD、`/mri/999999` 统一错误信封

## 三、已知限制

1. AI 结果为基线 / 占位数据，未接入真实模型。
2. 分割掩膜为模拟椭球，非真实 nnUNet / MedNeXt 输出。
3. 测距按体素数计算，未引入 spacing 换算（当前 spacing=1.0）。
4. 无登录 / 权限体系。
5. 数据库为 SQLite 单文件，生产需升级 PostgreSQL。
6. `reports.py` 为遗留接口（硬编码路径），预处理流程未与 AI 分析打通。
7. 前端为单 chunk，需路由级代码分割。
